# CryptoPanim

A pixel-art virtual world and NFT avatar experience.

## Vision

CryptoPanim is a Web3 social environment inspired by virtual worlds such as Gaia Online. Users will be able to create and customize their own pixel-art avatars, connect their wallets, and eventually explore virtual spaces where they can interact and chat with other users.

## Initial Development Goals

- Build a pixel-art visual environment.
- Create a customizable avatar system.
- Support outfits, hairstyles, accessories, and other avatar traits.
- Prepare for EVM wallet connectivity.
- Establish the foundation for future social spaces and in-game chat.
- Explore NFT ownership integration for avatars and wearable items.

## Technology

- Next.js
- TypeScript
- JavaScript
- CSS
- Web3 wallet connectivity
